# SplitEdge product requirements

The authoritative product requirements document is maintained as `SplitEdge_Product_Requirements_Document.md` with the project planning artifacts.

The locked MVP is:

- NBA only
- Player props only
- Opponent-specific historical analysis
- User-entered prop lines
- Points, rebounds, assists, three-pointers, and combination props
- Matchup and baseline comparisons
- Supporting game-level evidence
- Sample-quality and data-freshness warnings
- $0/month target operating cost

Before implementing a feature, verify that it is included in the authoritative PRD. Deferred features must not enter the MVP without an explicit scope decision.
